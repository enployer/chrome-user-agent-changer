## Installation

### 1 — Install the Magisk Module

Download `UAChangerChrome-module.zip` from the [Releases](../../releases/latest) page.

Open **Magisk Manager → Modules → Install from ZIP** → select the file → reboot.

### 2 — Install the App

Download `UAChangerChrome.apk` from the [Releases](../../releases/latest) page and install it.

### 3 — Apply a User Agent

1. Open the app → grant root permission when prompted
2. Confirm the **ROOT ✓** and **Chrome ✓** indicators are green
3. Browse or filter presets to find your target device
4. Tap a preset → tap **APPLY**
5. Chrome restarts automatically → new user agent is active

**Verify your UA:** Open `https://httpbin.org/user-agent` in Chrome.
